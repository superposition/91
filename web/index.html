A small instrument.
A band to play with.

NAIWAN 91 is a city-pop Songbook and performance instrument. Three original songs give you moving harmony, independent DX keys and bass, and phrase-timed swells. Keep a home key, leave space for your instrument, and steer the band.

Play the emulatorFollow the Rust migration

The emulator runs in your browser. No FM-1 is required. Audio starts only when you press Switch on.

One instrument, an incremental Rust migration. Songbook planning, bass decisions, pack/session codecs and the bounded command queue run in shared Rust libraries. Synthesis, the application and the instrument UI still run in C. The emulator labels the active Rust path and exposes its counters.

The downloadable hardware package is @@VERSION@@. Browser migration work and physical firmware qualification are tracked separately.

Play a song, then shape it

Musical controls first. Detailed pages when you need them.

Three authored songs

Velvet Changes, Afterhours and Neon Turnaround use written destinations, voice-led sixth/diminished harmony and 8/16-bar sections. PRESETS chooses the song.

Keys, bass and swells

Independent DX roles, gate and release, touch, brightness and texture. SELECT opens Arrangement, DX Keys, DX Bass and Swells.

Keep the phrase alive

Hold a section, request a related idea, change the bass feel or queue the next section. Key and form changes preserve the phrase boundary.

What runs in Rust

  • Checked compact musical types and stable parameter metadata
  • Borrowed Jam Pack views and explicit session codecs
  • Deterministic phrase planning and bass-event decisions
  • A bounded 1,024-word command queue and browser integration tested against the C reference

What comes next

  • Coherent snapshots and application ownership
  • Transport, synthesis, effects and UI migration
  • Physical compiler/runtime qualification
