# Historical browser API prototype

This directory contains an older AMB-style API frontend and its build. It is not copied into the current NAIWAN site and does not represent the current Songbook/Rust checkpoint. The supported browser instrument is `web/emu`, built into `/emu/` by `tools/make_pages_site.py`.

Retirement or archival of this prototype is tracked in [web ticket #35](https://github.com/superposition/91/issues/35). Its source history and authorship are retained until that review is complete.
